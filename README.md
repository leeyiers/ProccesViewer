# Process Viewer

Simple Windows process viewer made in C++.

Created by **Leeyiers**

---

## Description

Process Viewer is a lightweight tool that displays all running processes on your Windows system.  
It shows the process name and PID in a fast and minimal console interface.

Designed to be simple, clean and lightweight without unnecessary features.

---

## Features

- View all running processes
- Shows Process IDs (PID)
- Fast and lightweight
- Minimal CPU and RAM usage
- Console based UI
- Windows 10 / Windows 11 support

---

## Usage

1. Open `ProcessViewer.exe`
2. Wait for the process list to load
3. View all active processes
4. Press any key to close

---
